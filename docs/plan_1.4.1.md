## 明确不做

- **公有账户池**：保留接口不实现（待 Steam 放开限制；用户决策）
- 🔴 **注入类工具**（CreamAPI/GreenLuma/Steamless）：DRM 绕过 = 违法红线（DMCA §1201 + SSA），公开仓库不得纳入
- `swdm://` 协议注册：剪贴板方案覆盖 95%
- Nexus/ModDB/Paradox 站点 provider：解决不了工坊独占痛点
- ETag/304 条件请求：实测 Steam HTML 与 API JSON 均不支持
- 标签页切换动画：违背精简原则
- 便携 zip / 开机自启（速度报告 B3-portable / B4，P2，本期饱满）

详见 docs/feature_review_1.4.1.md。

## 关键结论（绕过调研）

- **不存在合规的"绕过正版限制"的方案**：所有权校验三层设防（license 检查 / file_url 签名发放 / depot key 解密），匿名只在 Valve 明确开放的 app 上可用，是设计而非缺陷
- **唯一合规解法 = 私人账户 provider**（C3）
- **变量监控**：Valve 官方 issue `steam-for-linux#13474` 诉求 scoped server token（只许下载指定 app 工坊、可吊销）——若采纳，受限 App 匿名下载将被官方层面解决。**每轮迭代复查**
