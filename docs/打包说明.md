# SWDM 打包说明

## 产物概览

| 产物 | 路径 | 说明 |
|---|---|---|
| 绿色版（免安装） | `build/dist/SWDM/` | onedir 目录，可直接运行 `SWDM.exe`；拷贝即用 |
| 安装包 | `installer/Output/SWDM-Setup-1.0.0.exe` | Inno Setup 安装程序（含桌面/开始菜单快捷方式、卸载数据保留选项） |
| 打包规格 | `swdm.spec` | PyInstaller（onedir / windowed） |
| 安装脚本 | `installer/swdm.iss` | Inno Setup 6 脚本 |
| 应用图标 | `swdm/resources/icon.ico` | 由 `tests/make_icon.py` 生成（Pillow 绘制） |

## 一键构建

环境要求：Python 3.12 + 依赖（`pip install -r requirements.txt`）+ `pip install pyinstaller`，以及 Inno Setup 6（`ISCC.exe` 在 PATH，或位于 `C:\Program Files (x86)\Inno Setup 6\`）。

```powershell
# 1) 生成图标（若 swdm/resources/icon.ico 不存在）
python tests/make_icon.py

# 2) PyInstaller 构建（约 1-3 分钟）
python -m PyInstaller swdm.spec --noconfirm --workpath build --distpath build/dist

# 3) Inno Setup 编译安装包（约 1-2 分钟）
ISCC installer\swdm.iss
# 或完整路径：
& "C:\Program Files (x86)\Inno Setup 6\ISCC.exe" installer\swdm.iss
```

构建产物：
- 绿色版：`build/dist/SWDM/SWDM.exe`
- 安装包：`installer/Output/SWDM-Setup-1.0.0.exe`

## 打包要点（已踩坑/优化）

1. **windowed 模式**：`console=False`，启动无控制台黑框；调试可临时改 `console=True` 观察 stdout。
2. **hiddenimports 必须显式声明**：`truststore`、`keyring`（含 `keyring.backends.chained` / `Windows` / `fail` / `null`）在代码中是函数内延迟导入，PyInstaller 静态分析会漏掉，缺失会导致 HTTPS 与密码存储在打包后失效。spec 中还用 `collect_submodules` / `copy_metadata` 补全。
3. **PySide6 按需收集**：不使用 `collect_all("PySide6")`，依赖 PyInstaller 内置 hook 自动收集实际用到的插件（platforms/imageformats/styles/tls），并在 `excludes` 中排除 WebEngine / Quick / Multimedia / 3D / Charts 等未使用的大模块，体积从约 400MB 压缩到约 40MB（安装包压缩后）。
4. **关闭 UPX**：`upx=False`——UPX 压缩 Qt 二进制易触发杀毒软件误报。
5. **steamcmd 不打包**：安装包不含 steamcmd（约 50MB 且需保持更新）。程序启动时自动检测系统已安装的 SteamCMD（如 `C:\Program Files (x86)\steamcmd\steamcmd.exe`）；未安装时在「设置 → SteamCMD 引擎」一键部署（从 `https://steamcdn-a.akamaihd.net/client/steamcmd_win32.zip` 下载解压到 `%APPDATA%\SWDM\steamcmd`）。
6. **便携模式**：在绿色版目录（`build/dist/SWDM/`）放入空的 `portable.marker` 文件，数据目录从 `%APPDATA%\SWDM` 切换为程序目录下的 `data/`，实现 U 盘携带。
7. **卸载策略**：Inno Setup 卸载界面提供「保留用户数据」复选框（默认勾选），配置/mod 库/缓存/日志位于 `%APPDATA%\SWDM`。

## 验证清单

- [ ] `build/dist/SWDM/SWDM.exe` 启动后 5 秒内不退出（GUI 正常）
- [ ] 工坊浏览页能加载出 mod 列表（需联网）

## 常见问题

| 问题 | 原因 | 解决 |
|---|---|---|
| 启动即退出，无窗口 | 缺 Qt 平台插件 | 检查 `_internal/PySide6/plugins/platforms/` 是否存在；用 `console=True` 重新构建看报错 |
| 浏览/下载全失败 "certificate verify failed" | truststore 未打包 | 确认 spec 中 `hiddenimports` 含 `truststore` 且 `collect_data_files("truststore")` 已执行 |
| keyring 保存密码失效 | keyring 后端未收集 | 确认 `keyring.backends.chained` / `Windows` 在 hiddenimports |
| 安装包编译失败 "ChineseSimplified.isl not found" | Inno Language 文件缺失 | 检查 Inno Setup 6 是否完整安装；或改用 `compiler:Default.isl` |
| steamcmd 首次下载慢 | 需自更新 | 正常现象，等待完成；失败可在「设置」重新部署 |
| 杀软误报 | 未签名 | 可选：配置 `codesign_identity` 对 exe 签名 |
