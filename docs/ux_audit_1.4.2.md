## 二、1.4.2 UX 改进候选（U1–U13）

格式：问题(代码位置)/用户影响/建议/工作量(人日)/三原则(精简·体感·基本功能)

**U1【P0】工坊页空结果无中央空态引导** — workshop_tab.py:1081-1089 只有一行状态小字；下载页库页都有 B6 空态。新手最常卡在"搜不到"且无出口。仿库页加空态面板（0 命中→换词/用标签栏；末页→回上一页）+「清除搜索与标签」按钮。0.5-1 人日，复用现有模式。精简✔ 体感✔ 基本✔。同时消除 E5。

**U2【P0】「清除已完成」实清失败/已取消行** — downloads_tab.py:289-309。想保留失败行的用户一键全没（文件在库但重试入口丢）。改只清成功行+二次确认；失败行交给「↻ 重试失败」。0.3。精简✔ 体感✔ 基本✔。

**U3【P0】库页检查更新运行中无法取消** — steam_api.py:476 已有 cancel 回调，但 library_tab.py:174/382 的 _check_cancel 恒 False（UI 层死代码），按钮禁用。大库检查几分钟不能中止。运行时按钮变「⏹ 取消检查」。0.3。精简✔ 体感✔ 基本✔。

**U4【P0】下载勾选入队后勾选集合不清空** — workshop_tab.py:1304-1332；按钮仍显示「下载勾选 (n)」。重复点击状态栏仍提示"已加入队列"（核心层去重仅记日志）造成重复下载误解，且需手动取消勾选。入队后清空 _checked_ids+复位按钮。0.2。三项✔。

**U5【P1】steamcmd 忙碌动画无文字** — downloads_tab.py:185-187、workshop_tab.py:240-243 setRange(0,0)+隐藏文字，只转圈。"转了多久/有无进展"不可知。加 tooltip「steamcmd 通道不输出逐字节数据，正在下载中」或信息列追加提示。0.2。三项✔。

**U6【P1】暂停无逐行反馈** — 仅状态条「⏸ 已暂停」(downloads_tab.py:351)，排队行仍显示"排队中"，分不清会不会开始。暂停态行文案追加「（已暂停）」或灰显。0.3。三项✔。

**U7【P1】设置页唯一保存按钮在长滚动页最底部** — settings_tab.py:320-322。在后面的分组改完要滚到底保存；且部分项即时生效易让人漏保存（通道/代理需保存）。保存按钮常驻吸底。0.3+回归。精简✔ 体感✔ 基本✔。

**U8【P1】导入列表不提示跳过数** — library_tab.py:634 只弹成功数。换机迁移不知几条废记录被吞。弹窗改「已导入 n 条，跳过 m 条无效记录」。0.1。对应 E8。

**U9【P1】游戏下拉「★ 收藏」占位行可点无语义** — workshop_tab.py:552 itemData=""；点选后 appid 为空→列表提示"请先选择或输入游戏 AppID"并清空。用户当成"查看收藏"功能。占位行改不可选或移除（收藏已由 ★ 前缀条目表达）。0.2。三项✔。

**U10【P2】标签栏空态三态不分** — tag_bar.py:175-179、workshop_tab.py:1575-1580。分不清加载中/无标签/拉取失败。header 文案区分三态（含"点 🏷 标签… 重试"）。0.2。纯文案。

**U11【P2】剪贴板入队无托盘通知** — main_window.py:399-401 只有 5s 状态栏消息；用户在别的程序前无感知。走托盘气泡（复用 _notify_download_finished 的 showMessage）「已加入下载队列：<标题>」。0.2。

**U12【P2，先文档后代码】评论区默认折叠发现性** — detail_dialog.py:825。手册把评论列为详情弹窗四大内容之一但默认看不到。先改手册 E10（零代码说明"评论默认折叠、点标题展开"），代码侧加悬停提示；折叠策略本身不改（展开会顶掉简介/依赖区）。文档 0 / 代码 0.2。

**U13【P2 可延后】调试页日志无过滤** — debug_tab.py:71-78 只有追加+自动滚动。反馈 bug 要在几千行日志里翻。加级别下拉+关键字过滤（作用于内存环形缓冲）。1 人日。

## 三、汇总

代码有但手册未写的功能：工坊页🔍搜索按钮+匿名/登录标识；库页↻刷新+双击打开目录；详情弹窗关闭按钮/Steam 社区链接/评论折叠/标签chip筛选/作者搜索/依赖标题搜索/依赖行独立下载；下载页状态条五段式。

优先级：P0 = U1 工坊空态、U2 清除已完成语义、U3 检查更新可取消、U4 勾选清空；P1 = U5-U9；P2 = U10-U13。手册侧 E11（changelog_1.4.1.md 缺失）是 1.4.1 发布阻塞项，打包前必须解决；E1/E3/E5/E10/E14 建议随 1.4.2 功能同步修订手册后再版。
