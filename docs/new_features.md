# 新功能方案清单（SWDM 1.3.6 基线）

> 基于现有能力（匿名列表抓取、标签筛选、steamcmd 串行下载、mod 库管理、
> mod 包导入导出、依赖下载、冲突检测）提出。原则：实用优先，不堆砌。

## 推荐方案

### F1. 下载队列批量管理（推荐 ★★★，工作量：小）
- **描述**：下载页支持"全部暂停/全部继续/清空已完成/失败重试全部"。
- **用户价值**：批量下载 20 个 mod 时逐个操作极繁琐；这是最高频诉求。
- **实现要点**：`downloads_tab.py` 顶部工具栏加 4 个按钮，调用
  `DownloadManager` 已有的 pause/resume/cancel 接口批量遍历。
- **涉及模块**：`gui/downloads_tab.py`、`core/downloader.py`
- **工作量**：小（接口已存在，只需批量调用 + UI）

### F2. mod 一键更新检查（推荐 ★★★，工作量：中）
- **描述**：库页加"检查更新"按钮，对比本地 mod 与工坊最新版本
  （time_updated），列出有更新的并提供批量更新。
- **用户价值**：mod 更新频繁，当前无法知道哪些过期了。
- **实现要点**：复用 `get_file_details` 批量查 time_updated，与本地
  `ModRecord` 记录的更新时间比对；批量加入下载队列（覆盖安装）。
- **涉及模块**：`gui/library_tab.py`、`core/steam_api.py`、`core/mod_library.py`
- **工作量**：中

### F3. 收藏夹与历史记录（推荐 ★★☆，工作量：中）
- **描述**：浏览过的 mod 自动留痕（可开关）；支持收藏 mod，库页一键筛选收藏。
- **用户价值**：工坊页关掉就找不到之前看中的 mod。
- **实现要点**：详情页打开时记录到本地库（已有 `ModRecord` 基础），
  library_tab 加收藏筛选 + 时间排序视图。
- **涉及模块**：`gui/library_tab.py`、`gui/detail_dialog.py`、`core/mod_library.py`
- **工作量**：中

### F4. 下载完成通知（推荐 ★★☆，工作量：小）
- **描述**：下载完成时系统托盘通知 + 任务栏闪烁；最小化到托盘。
- **用户价值**：下载几个 G 的 mod 时不必一直盯着窗口。
- **实现要点**：`QSystemTrayIcon` + `showMessage`；下载完成信号已有
  （DownloadEventBridge.finished）。
- **涉及模块**：`gui/main_window.py`、`gui/downloads_tab.py`
- **工作量**：小

### F5. mod 包一键导出/导入分享（推荐 ★★☆，工作量：中）
- **描述**：把选中的 mod 列表（id + 名称 + 标签）导出为可分享文件；
  他人导入后一键批量下载。
- **用户价值**：服务器/联机圈子标配需求（modpack 分享）。
- **实现要点**：导出 JSON（已有 mod 包功能基础，需确认当前是否只是目录
  导入）；导入时批量加入下载队列。
- **涉及模块**：`gui/library_tab.py`、`core/mod_pack.py`（若存在）
- **工作量**：中

### F6. 多游戏并行下载（可选 ★☆☆，工作量：大）
- **描述**：不同游戏的 mod 可并行下载（steamcmd 实例按 appid 隔离）。
- **用户价值**：跨游戏批量下载时总时长大幅缩短。
- **实现要点**：`_engine_lock` 目前全局串行；改为按 appid 分锁，每个 appid
  一个 steamcmd 工作目录。风险较高（竞态曾导致 1.3.4 的崩溃）。
- **涉及模块**：`core/downloader.py`、`core/steamcmd_engine.py`
- **工作量**：大（且与 1.3.4 稳定性成果冲突，建议缓行）

### F7. 黑名单/过滤词（可选 ★☆☆，工作量：小）
- **描述**：列表中按标题关键词隐藏不感兴趣的 mod（如 "Dead" "废弃"）。
- **用户价值**：工坊列表里废弃 mod 多，浏览噪音大。
- **实现要点**：`_populate` 时按配置的关键词列表过滤，设置页管理关键词。
- **涉及模块**：`gui/workshop_tab.py`、`gui/settings_tab.py`、`core/conf.py`
- **工作量**：小

## 建议优先级
1. **F1**（批量管理）+ **F4**（完成通知）：小工作量、高频诉求，先做。
2. **F2**（更新检查）+ **F7**（过滤词）：中价值，第二批。
3. **F3**（收藏/历史）+ **F5**（mod 包分享）：完善体验。
4. **F6**（多游戏并行）：风险高收益有限，缓行。
